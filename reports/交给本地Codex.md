# 本地 Windows 验收接续

目标是将 R1 资源候选推进为可使用的中文补丁。先读取 README.md 和兼容性与实机测试报告.md，保留本包的资源读取证据，不把云端 PASS 扩大成 Windows PASS。

在原版 6.13.3.1 安装旁使用 Install.cmd 创建独立副本，运行 Probe-Windows.cmd 后启动专用中文启动器。逐项验收 Windows验收清单.csv，记录截图、工程保存恢复、实际合成与音频导出证据；检查各 DPI 的布局。优先定位未翻译的固定标签与原生效果器文字，区分可由资源补齐的内容和需要修改主体或原生模块的内容。

插件单独处理：先确认实际授权、DAW、VST3/ARA 外层和 COM 托管布局，证明宿主执行了中文适配入口。不要让全局环境变量或 COM 注册改变日常 DAW；需要注册或改宿主路径时，先形成可恢复的具体方案。Lite 的功能限制与激活流程保持原样。

使用 .NET 8 SDK 完整运行 Build.cmd，核对输出程序集版本、文化、733键及资源读回。对无法使用启动适配器的路径，先提交必要性、影响范围及恢复方式，再考虑最小改动。完成实际界面与功能验收后更新报告，最终验证卸载可回到原版界面。

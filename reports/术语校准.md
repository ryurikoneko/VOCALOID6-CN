# 中文术语校准

校准日期：2026-11-09（北京时间）。本工程以实际日语资源键、主体英文资源及功能语境为基础；参考中文社区的习惯用词和既有中文适配，逐项决定译法。

| 概念 | 本工程采用 | 校准依据 |
| --- | --- | --- |
| Voicebank | 声库 | 中文创作社区的常用简称，界面不再混用歌声库、音源库、声音 |
| Part | 片段 | 既有适配中已使用片段；与轨道、音符区分 |
| Phoneme / phonetic symbols | 音素 / 音素符号 | V6 厂商中文介绍使用音素；不把全部编码称为国际音标 |
| Expression | 表情 | INTERNET 的 V6 中文介绍使用表情工具 |
| Timing | 音素时序 | 明确指向音素的发生时间，避免泛称时机或计时工具 |
| Leading / Following | 前部 / 后部 | 按音符的时间方向命名 |
| Transition | 音高过渡 | 保留与 Expression 的区别 |
| Drift | 音高漂移 | 保留与 Transition、Fine Pitch 的区别 |
| Take | 演唱变体（Take） | 根据 V6 生成人声叠唱的语境命名，保留英文便于对照教程 |
| VEL / Velocity | 辅音时长（VEL） | VOCALOID 中影响辅音发音，不能按通用 MIDI 直接解释为音量力度 |
| POR | 滑音时机（POR） | 区分过渡发生时机和过渡所需时长 |
| Attack / Release | 起音 / 释音 | 效果功能，统一中文术语并在术语表保留英文 |

731条日语资源本身没有全部参数名称，例如 VEL、DYN 等名称还涉及主体元数据或其他界面内容。术语表提供这些概念的中文解释，不代表对应英文标签已在窗口中被替换。界面最终用词需结合截图验收。

## 已核对的资料

1. [INTERNET：VOCALOID6 AI Megpoid 中文新功能](https://www.ssw.co.jp/products/vocaloid6/megpoid_cn/new-function.html)。作为厂商中文说明，核对表情、音高、颤音、音素及 Take 功能语境。
2. [Mikai Music：初音未来 V4C 中文版 Piapro Studio 教程](https://www.mikaimusic.com/post/mikai-post-6.html)。教程作者原发，核对 VEL、DYN、PIT、PBS 及钢琴窗等中文创作语境。
3. [既有 VOCALOID6 中文适配](https://github.com/zwnweixiao/VOCALOID6_CN)。核对公开 CSV，固定参考版本 `234bc72b3531e65a2ac4c920b3b1f79c3bab74ed`。借鉴通用术语，不使用该项目 DLL；没有用旧版键数量代替 6.13.3.1 的实际提取。
4. [VCPedia：VOCALOID 参数](https://vcpedia.cn/zh-hans/VOCALOID)。作为社区用词补充；其版本信息较旧，不作为本版本功能或数值行为的最终依据。

相同概念在旧适配中存在不同译法。本工程统一片段、轨道、声库、风格预设；对功能语义不准确的旧译文独立修正。

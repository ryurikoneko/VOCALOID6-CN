## 框架和加载机制

用户提供的 Editor 主体和插件主体均为 6.13.3.1，runtimeconfig 指定 .NET 8 和 Microsoft.WindowsDesktop.App 8.0.0。资源程序集未带强名称公钥，按原程序集名称、版本、资源基名及文化信息构建，无需签名伪造或程序集重写。

资源基名为 `Yamaha.VOCALOID.Properties.Resources`。资源位置为 `zh-CN/VOCALOID6.resources.dll` 和 `zh-CN/VOCALOID6Plugin.resources.dll`。资源文化为 zh-CN，程序集版本 6.13.3.1。

编辑器与插件各自的 `App.SetupAppLanguage` 使用 CultureKindEnum 的允许列表；其成员只有 Japanese 与 USEnglish。当前 UI 文化不在列表时回退到英语。只放置 zh-CN 文件夹不能完成接入。

本候选的启动适配器通过 .NET Startup Hook，在指定副本目录内的目标程序集加载时，将生成资源类的 `Culture` 属性设为 zh-CN。该属性是所有强类型资源访问器调用 ResourceManager 时的显式文化参数，因此不依赖默认 UI 文化是否被启动代码改成英语。它不设置数值/日期文化。

适配器只匹配指定目录的 VOCALOID6/VOCALOID6Plugin、6.13.3.1 版本。它新增可执行代码并改变该进程的资源选择；资源类或加载顺序改变可能导致适配失效或启动错误。使用原始 VOCALOID6.exe 可绕过专用启动器；卸载可移除适配器。原主体 DLL 未修改。

## 插件与 Lite 的限制

原版资源明确提示 Lite 版不支持 VST/AU。汉化工具保留该限制与激活流程。

当前上传包有 VOCALOID6Plugin.dll 和 comhost，但没有完整的外层 VST3/ARA 安装布局。安装工具只制作 Editor 副本，不注册 COM、不替换系统 VST3、不更改 DAW 搜索路径。副本中有插件中文资源，但实际 DAW 并未自动指向该副本。

Startup Hook 以 Main 之前执行为设计入口，原生 DAW 的 COM/hostfxr 启动路径是否执行同一入口尚无实机证据。插件接入需要在有效授权与实际安装布局中单独验证，不能由本探针结果推导为通过。
